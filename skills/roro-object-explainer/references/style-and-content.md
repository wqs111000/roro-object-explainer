# 视觉与内容标准

默认原创纸张和彩铅混合质感，轻水彩铺色、圆润清晰轮廓、柔和日光和低饱和背景。机械部件比背景清晰，金属以哑光插画呈现。用户可以更换风格；不要点名模仿插画家或复刻第三方构图。

一个主要物品，一个视觉焦点。背景只托住生活情境，不堆满工具和装饰。角色可选，身份来自用户有权使用且已查看的参考；画风参考只提供媒介、色彩和光线，不复制人物。角色应在安全位置观察，不伸入转动机械，不引导儿童接电拆解、接触制冷剂或进入封闭容器。

标题使用孩子会问的具体问题。部件保留真实名称加短用途；类比不能替代科学定义。2–4 个短动作通常足够，但不能为了凑步数漏掉关键连接。至多一个观察问题，不要求操作电器。约 80–140 个汉字是密度参考，优先保证大字和结构可读性。

可省略螺丝和次要细管，不能删掉决定机制的连接。例如压缩机不能被解释成制造冷风，液晶电视的背光不能被当作扬声器，后驱车的动力终点不能误标为前轮。改变技术类型后重新核实。

母版不含任何文字、数字、徽章、箭头或引线，也没有预留标题带和底部淡色条。最终页边距和纸色背景属于独立排版层。双视图是想象透视，不是角色真的拆开运行中的设备。

每个部件一枚编号，清单使用同号；颜色是辅助线索。编号贴近目标边缘，不压关键接点，也不能落到外壳、地面或角色身上。看不清时重构图或做局部放大，不能靠大概位置。当前渲染器支持直接编号，不支持局部放大和长引线。

至少记录七项：`style`、`character_identity`、`mechanism`、`number_placement`、`number_text_matching`、`readability`、`no_occlusion`。无角色时 `character_identity` 可为 `not_applicable`，仍写明原因。查看真实 PNG，确认中文没有缺字方框、文字没有重叠、主体完整、因果清楚。记录具体观察，不把尺寸检查当作看图。
